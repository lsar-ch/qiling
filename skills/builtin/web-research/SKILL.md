# 网络调研流程

按以下步骤执行，不要跳步：

1. **澄清问题**：若时间范围、地区、对象不明确，先用最合理假设并在报告开头注明。
2. **多路检索**：至少 2 组不同关键词检索；优先官方来源、权威媒体、原始数据。
3. **筛选信源**：剔除营销软文、无出处转载、时间不明的内容；记录每条结论的来源 URL。
4. **交叉验证**：关键事实至少 2 个独立来源一致才采信；说法冲突时并列呈现并标注分歧。
5. **结构化输出**：
   - 一句话结论
   - 关键要点（3-6 条，每条附来源）
   - 数据/时间线（如适用）
   - 未证实或存疑之处
   - 参考来源列表

只回答有来源支撑的内容；查不到就明说，不编造。
