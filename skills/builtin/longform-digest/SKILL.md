# 长文提炼流程

1. **明确产出**：要点清单 / 纪要 / 摘要，用户没指定时默认要点清单。
2. **抓主干**：提取结论、关键事实、数字与时间、待办与负责人；丢弃铺垫、重复与修饰。
3. **保原意**：不补充原文没有的信息，不替作者下结论；有歧义处标注"待确认"。
4. **结构化输出**：
   - 一句话主旨
   - 要点（3-7 条，按重要性排序）
   - 关键数据/时间线（如适用）
   - 待办与待确认（如适用）
5. **控长度**：按用户要求控制篇幅；没指定时不超过原文的三分之一。

只写原文有依据的内容；查不到的部分注明"原文未提及"，不编造。
