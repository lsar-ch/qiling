# 项目周报流程

1. **确定周期**：默认本周一至今；用户指定则按指定起止时间。
2. **收集素材**：任务记录（完成/进行中/失败）、关键对话与决策、记忆中的项目事实；只读取，不改数据。
3. **归纳成果**：按项目或主题分组，列已完成事项与产出物；一条一事，不堆砌流水账。
4. **识别风险**：进行中/受阻任务、待确认事项、依赖项，标明影响。
5. **结构化输出**：
   - 本周摘要（3-5 条）
   - 已完成（按项目分组）
   - 进行中与计划
   - 风险与待办
   - 下周重点

只写有记录支撑的事实；没有数据的部分注明"无记录"，不编造进度。
