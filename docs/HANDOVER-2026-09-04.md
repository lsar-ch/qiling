## 本轮结论
- 产品方向已收敛为“角色化、本地优先、懂项目记忆的 AI 工作伙伴”；任务执行采用 Codex/MCP 等现有能力集成，不自研通用 Computer Use
- Step 1~3 已验收；Step 4（语音闭环）服务端已落地，进入真机听测与收尾
- 语音供应商拍板：STT = DashScope `paraformer-realtime-v2`；TTS 主声 = MiniMax
  `speech-2.8-hd` + `Chinese (Mandarin)_Soft_Girl`（听感更像人，优于 DashScope 助理声）；
  克隆声 `deskmate_voice_01` 链路跑通（用户录音验证 OK），保留为角色自定义音色
- 语音交互定稿：默认常开能量 VAD；说「静默」后零回应；唤醒词默认「你好，千问」，
  绑定角色卡名称且可自定义
- 回声/重复问题按 Qwen-Audio-Agent 思路修复：播放与监听共用 AudioContext、
  播报期间不自动打断、播报结束 ~900ms 窗口内语音不送识别、相似文本抑制
- 长回复也能自动开口：后端新增 `speak_text`（短回复=全文；长回复=开头整句摘要 ≤120 字），
  SSE `done` 与 `conversation.completed` 均携带；前端长回复自动播摘要，全文可点 🔊 朗读。
  `check.sh` 全绿（35 项测试 + Web/Desktop typecheck），真机链路已验证
- 维持：本轮不配置多 Agent 协作、不开云服务，先把本地 V1 主链路跑完
