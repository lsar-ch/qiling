# 竞品与差异

## 结论

类似项目已经不少，尤其集中在三个方向：

1. `Live2D/虚拟形象 + 语音对话`
2. `长期记忆 + 主动对话`
3. `桌面 Agent / 工具调用 / 屏幕感知`

这说明“做一个桌面 AI 助手”本身不是空白赛道，但也说明你要做的不是从零想象，而是明确差异化。

## 代表项目

- `Warashi`：Live2D 形象、语音、长期记忆、主动对话，完成度高。
- `Soul-of-Waifu`：角色系统、四级记忆、RPG/桌面伴随式设计，概念完整。
- `Nexus`：本地优先、分阶段路线、隐私与陪伴优先，产品感较强。
- `my-neuro` / `Open-LLM-VTuber`：桌面角色、屏幕感知、语音交互、形象表现更成熟。
- `AIRI`、`Alice`、`Agent-Player`、`QwenPaw` 等：覆盖了记忆、技能、插件、跨平台、智能体调度等组合。

## 我的判断

你的项目仍然有必要做，但前提是别把自己定位成“又一个桌面聊天框”。

真正值得做的点是：

- 桌面挂件不是装饰，而是第一交互入口
- 角色状态反馈是产品核心，不是附属功能
- 主界面是工作台，挂件是伴随层
- 行为要像“在工作流里参与”，而不是只会回答问题
- 智能体、知识库、记忆、桌面控制要统一纳入一个调度层

如果只做聊天、记忆、语音，和已有项目差异不大。
如果把“桌面角色反馈 + 工作参与 + 多 Agent 编排”做成统一体验，就有明显价值。
