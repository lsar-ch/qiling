# 栖灵 V1 范围说明

## 1. V1 目标

V1 不追求做完整桌面智能体，而是验证一个明确产品假设：

> 有角色感、能语音交流、记得项目上下文的桌面伙伴，能够通过现有执行器帮助用户完成真实工作。

## 2. V1 必做

### 2.1 桌面挂件

- 2D 角色常驻、拖拽、双击打开主界面
- 空闲、聆听、思考、播报、执行、授权、完成状态
- 短回复气泡
- 状态由系统事件驱动

### 2.2 语音闭环

- 麦克风采集、VAD、STT、LLM、TTS
- 常开监听和自动断句
- 静默 / 唤醒词
- 播报停止和基础打断
- 回声和重复输入抑制
- 长回复摘要自动播报

### 2.3 对话和主界面

- 文字和语音对话
- SSE 流式回复
- 短回复挂件展示，长回复进入 Chat
- Home、Chat、Memory、My Agents、Settings 可访问

### 2.4 最小项目记忆

- 保存会话和任务事件
- 保存用户明确确认的偏好、项目进度和技术决策
- 支持查看、编辑、删除
- 支持 Obsidian 只读检索入口

### 2.5 一个真实工作闭环

至少完成一个窄场景：

```text
用户提出项目相关问题
→ 栖灵 读取当前上下文或项目记忆
→ 简单问题直接回答
→ 复杂代码任务交给 Codex
→ 返回进度和结果
→ 结果可归档到记忆
```

### 2.6 授权

- 高风险任务进入等待授权状态
- 授权前不执行
- 主界面展示操作目标和影响范围

## 3. V1 可选

- 多套基础角色卡
- 基础语气标签
- 浏览器只读搜索
- 低风险网页操作
- 简单主题设置

## 4. V1 不做

- 通用 Computer Use
- 完整桌面感知
- 自研视觉 Agent
- 多 Agent 并行编排
- 3D、Live2D 和复杂情绪系统
- 云端任务平台
- 角色/服装/声音市场
- 真正实时全双工语音

## 5. V1 验收场景

### 5.1 项目问答

用户说：“这个项目现在做到哪一步了？”

期望：

- 语音转写并进入对话
- 从项目记忆或当前资料中回答
- 挂件播报简短结论
- 主界面可查看依据和完整内容

### 5.2 Codex 任务

用户说：“帮我检查这个项目的代码结构并提出改造建议。”

期望：

- 判断为后台复杂任务
- 交给 Codex
- 挂件进入执行状态
- 主界面显示进度和结果
- 结果可保存为项目记忆

### 5.3 高风险授权

用户说：“删除这个项目里的临时文件。”

期望：

- 识别为高风险
- 进入等待授权
- 未授权前不执行

验收记录（2026-09-13，真实 UI 走一遍）：

- 分流结果 `task_3c56f5dab4`：`category=request_approval`、`risk_level=high`、`status=awaiting_approval`、`required_approval=true`、`preferred_executor=null`。
- 回复“这类操作需要先确认，我已经挂起等待授权。”，事件流出现 `task.approval_required`。
- 未授权前没有任何副作用：该任务没有生成任何 agent run（`/api/agent-runs` 查无此任务），执行器未被调用。
- 「我的智能体」页最近任务卡片显示 `request_approval · high · awaiting_approval`，需要用户显式操作才会继续。

## 6. V1 完成判断

只有以下链路全部可用，才算 V1 核心验证完成：

```text
挂件入口
→ 语音/文字对话
→ 项目记忆
→ 简单回答或 Codex 任务
→ 状态反馈
→ 授权控制
→ 结果回流
```
