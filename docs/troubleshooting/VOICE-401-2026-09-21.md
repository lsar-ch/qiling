# DeskMate 语音故障证据 — 2026-09-21

## 一句话根因
`DASHSCOPE_API_KEY` 已失效（HTTP 401 Unauthorized）。LLM 与 STT 用同一把 key，
所以语音对话整条链路不通。需要用户在阿里云百炼控制台重新生成并替换。

## 关键证据（12:37 实测）
- 直接调用 DashScope Recognition：`status_code=401, code=401, message="Unauthorized, your api-key is invalid!"`
- 兼容模式 LLM 鉴权：HTTP 401，`code=invalid_api_key`
- 失效 key 特征：长度 116、前缀 `sk-ws-H.EEHEHE`、非标准 `sk-` 直连格式（疑似被改写/污染）
- `/api/voice/status` 仍显示 STT/TTS `available=true`（该字段只检查配置不做鉴权，会误导）

## 次要 bug（适配器静默吞错）
`services/ai-service/app/speech/dashscope.py` 的 `_recognize_sync` 只取
`result.get_sentence()`，从不检查 `status_code/code/message`。
→ API 返回 401 时 sentence=None，被当成“未识别到有效语音”（422），掩盖真实的鉴权失败。
建议：识别前先判断 `result.status_code`，非 200 抛 SpeechProviderError 带上 message。
