# 栖灵 产品需求文档

## 1. 产品定位

栖灵 是一个本地优先、角色化、懂项目上下文的 AI 工作伙伴。

它不是单纯的聊天机器人，也不是通用 Computer Use 平台。栖灵 通过桌面挂件提供陪伴感和即时反馈，通过浏览器主界面承载长内容、记忆、设置和任务状态，并通过 Codex、MCP 等现有工具参与用户的实际工作。

核心表达：

> 一个有性格、记得你的项目、能陪你把事情做完的桌面 AI 伙伴。

产品由三层组成：

- 桌面挂件：常驻、语音入口、状态反馈、短回复
- 浏览器主界面：对话、项目记忆、任务详情、设置
- 本地 AI 服务：对话编排、语音、记忆、授权和外部工具调度

## 2. 目标用户

第一目标用户不是所有桌面用户，而是：

- 长期使用 AI 辅助工作的个人开发者和知识工作者
- 使用 Obsidian、代码编辑器、浏览器、Codex 或 MCP 的用户
- 希望 AI 不只是工具，而是具有稳定角色和持续上下文的用户

## 3. 核心问题

现有桌面宠物通常有角色感，但工作能力弱；现有桌面智能体通常能执行任务，但缺乏持续关系和可理解的反馈。

栖灵 要解决的是两者之间的断层：

- 用户可以自然地和它说话，而不是每次打开一个工具
- 它能记住用户的项目、偏好和决策
- 它能把复杂工作交给合适的执行器
- 它会解释正在做什么、为什么需要授权、结果是什么

## 4. 产品原则

1. **角色感服务于工作，不做无意义卖萌。**
2. **记忆优先服务于项目连续性，不追求无限保存。**
3. **执行能力采用集成，不自研通用 Computer Use。**
4. **本地优先，敏感数据和权限边界可见。**
5. **短反馈在挂件完成，长内容进入主界面。**
6. **先保证可靠可用，再追求全双工和复杂情绪。**

## 5. 产品差异化

栖灵 的差异不在单项能力，而在组合体验：

- 桌面挂件是实际交互入口，而不是装饰
- 角色状态是任务状态的可视化
- 角色能持续记住用户的项目上下文
- 复杂任务由 Codex、MCP 或其他执行器完成
- 用户看到的是一个有性格的工作伙伴，而不是裸露的工具链

## 6. 核心能力

### 6.1 角色与陪伴

- 固定角色名称、性格、语言风格和行为边界
- 支持基础形象和声音配置
- 支持空闲、聆听、思考、播报、执行、授权、完成等状态
- 不主动频繁打扰用户
- 情绪表达只作为状态反馈，不替代明确的任务状态

### 6.2 语音交互

- 常开能量 VAD 和自动断句
- STT、LLM、TTS 闭环
- 播报停止和基础打断
- 静默 / 唤醒词
- 长回复自动播报摘要，全文在主界面展示

V1 对外表述为“自然语音交互和可打断播报”，不承诺真正实时全双工。实时全双工作为后续技术路线。

### 6.3 项目记忆

优先记忆与工作连续性直接相关的内容：

- 用户偏好
- 当前项目目标和进度
- 已确认的技术决策
- 最近任务及结果
- 用户明确要求保存的事实

记忆必须可查看、编辑、删除，并有来源和时间信息。

### 6.4 工作参与

第一阶段只验证窄场景：

- 读取并总结当前项目
- 查询 Obsidian 项目资料
- 整理代码或技术方案
- 将复杂代码任务交给 Codex
- 汇报后台任务进度和结果

栖灵 负责理解、上下文、角色交互、授权和结果呈现；具体操作优先交给已有 Agent、MCP 或浏览器工具。

### 6.5 授权与安全

以下操作必须先授权：

- 删除、发送、提交、支付
- 修改外部数据或配置
- 写入知识库或项目文件
- 任何用户明确标记为高风险的操作

授权信息必须说明目标、范围和潜在外部影响。

## 7. 主界面

主界面使用默认浏览器打开，包含：

- Home：当前角色、项目状态、最近任务
- Chat：文字/语音对话和长回复
- Memory：项目记忆和用户偏好
- Knowledge Base：Obsidian 检索入口
- My Agents：Codex 等执行器状态
- Settings：模型、语音、角色、唤醒词和权限配置

## 8. MVP

MVP 必须证明：

1. 用户可以通过桌面挂件完成文字和语音对话
2. 角色状态和任务状态有清晰反馈
3. 系统能记住并展示项目上下文
4. 一个复杂项目任务可以交给 Codex 并回流结果
5. 高风险动作不会未经授权执行

## 9. 非目标

V1 不做：

- 通用操作系统级 Computer Use
- 自研通用桌面视觉模型
- 多 Agent 同时编排
- 复杂插件市场和云端任务平台
- 3D / Live2D 深度角色系统
- 无限角色、服装和用户内容市场
- 一开始就实现真正实时全双工

## 10. 成功标准

用户连续使用一周后，能够明确感受到：

- 栖灵 记得自己的项目和工作习惯
- 语音交互比打开普通聊天窗口更自然
- 任务执行过程更容易理解和控制
- 它既有角色感，又确实能帮助完成工作
